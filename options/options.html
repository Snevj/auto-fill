Application Preferences

Demographic / EEO questions (gender, race, veteran, disability status, etc.) are never auto-filled by this extension — those are always left for you to answer directly.

Answer Style Templates

Paste a few real questions you've answered before, with your actual answers. The AI uses these as style examples (tone, length, voice) when it drafts answers to new, similar questions — it does not answer questions it has no basis for.

Profiles

Save multiple full copies of your profile — e.g. one tuned for ML/AI roles, one for general software engineering — if you apply to different kinds of positions with different resumes. Active profile: Default. The popup will suggest switching profiles when a job page's title/description looks like a better match for a saved preset.

AI Settings — Google Gemini

Get a free API key at aistudio.google.com/apikey. The key is stored only in your browser's local extension storage and is sent only to Google's Gemini API, never anywhere else.

Type any model ID Google currently supports. Google periodically retires older models (this is why autofill can suddenly stop working) — if that happens, click "Test connection" below; a failure there means it's time to switch to a current model ID from the model list.

Advanced

How many open-ended questions to send to Gemini in one autofill run. Lower this to save API quota on long forms; raise it if long forms leave too many questions untouched.
